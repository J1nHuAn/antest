答满 12 题可看简版，继续答满 30 题生成完整版；全同答案会判为无效。
生日选填。手机浏览器可长按海报图片保存；桌面端可点击“保存图片”。

puppy 快乐小狗 / cat 敏感小猫 / bear 热血小熊 / panther 独行黑豹
